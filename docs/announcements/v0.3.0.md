# Hanazar Transfer v0.3.0

发布日期：2026-08-10

本次版本让 GitHub Pages 从展示页升级为真正可用的纯前端传输工具。无需后端，两台设备交换一次邀请和回复后，即可通过 WebRTC 加密直传文件与文字。

## 本次更新

- 新增独立的 P2P 直传页面，GitHub Pages 与本地静态服务均可使用
- 支持邀请链接、回复码、系统分享和剪贴板复制，连接信息不会提交给 API
- 支持双向文字、多文件、零字节文件、拖放、发送进度、取消和下载记录
- 使用可靠有序 DataChannel、16 KiB 分块和缓冲区背压，降低大文件传输时的内存与丢包风险
- 增加接收确认与异常清理，防止未完整文件被误判为可下载
- 修复传输中取消导致残留分块触发协议断线的问题
- 修复发送期间仍可改动文件队列，以及禁用拖放区可能打开本地文件的问题
- 加强损坏邀请、复制失败、浏览器不支持、连接竞态和断线恢复反馈
- 完成 320px、390px、平板与桌面布局检查，并补齐键盘焦点、读屏状态和点击区域

提示音继续默认关闭，仅在用户主动开启后播放短促的连接、发送和接收反馈。文件传输属于短时工具场景，因此不加入持续 BGM，避免干扰并遵守浏览器自动播放限制。

## 使用提醒

打开 [GitHub Pages](https://hzagaming.github.io/HanazarTransfer/) 后进入“P2P 直传”即可使用。纯前端模式没有设备发现与 TURN 中继，同一 Wi-Fi 成功率最高；企业网络、访客网络或跨网环境可能无法直连。需要自动发现时，仍可在局域网电脑运行 `npm start` 使用原服务模式。
