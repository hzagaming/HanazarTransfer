# Hanazar Transfer v0.2.0

发布日期：2026-08-08

本次版本把 Hanazar Transfer 从传输码工具升级为更完整的局域网设备互传体验。连接同一局域网并打开本机地址的设备会自动互相发现，可直接发送文件或保留原格式的文字；传输码仍可作为备用方式。

## 本次更新

- 新增附近设备发现、实时在线状态、文件投递通知和文字互传
- 新增上传取消，失败或取消后自动清理未完成传输
- 网络中断后持续重试设备注册，异常事件不会打断页面交互
- 增加设备注册回收、在线数量上限和同源写请求校验
- 完善键盘 Tab 切换、弹窗焦点管理、Esc 关闭和背景交互隔离
- 修复未选择设备时的空白操作栏、文字首尾空白丢失和多处移动端细节
- 提高强调色与辅助文字对比度，覆盖 320px 至桌面宽屏布局
- 新增默认关闭的轻量提示音开关，并记住用户选择

没有加入循环背景音乐：文件传输属于短时工具场景，持续 BGM 会干扰使用，也受浏览器自动播放策略限制。提示音仅在用户主动开启后播放。

## 使用提醒

GitHub Pages 只能展示静态页面，无法承担设备发现、事件流和文件中转。请在局域网内的一台电脑运行 `npm start`，再让其他设备打开终端显示的局域网 IP 地址。
